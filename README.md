# Practical Python: From Code to Automation

An evolving, hands-on workshop to help new-to-intermediate
coders learn to use Python to solve practical, everyday
problems.

## Overview

This workshop is designed for learners with some prior
programming experience who want to become more comfortable
using Python for practical tasks, automation, and working
with real-world data.

The emphasis is on understanding useful programming
concepts and applying them to meaningful problems — not
simply learning Python syntax.

The course is being developed as a collection of practical
lessons, guided exercises, and small projects.

## Learning Objectives

By the end of the workshop, participants should be better
prepared to:

- Write and organize Python programs.
- Work with strings, lists, dictionaries, and other
  common data structures.
- Read, process, and generate files in common formats.
- Handle errors and unexpected input.
- Use Python libraries to extend their programs.
- Automate repetitive tasks.
- Retrieve and process information from the web.
- Build small, practical Python applications.

## Tentative Workshop Outline

### Day 1: Python for Practical Problem-Solving

- Python fundamentals review
- Data structures and useful built-in functions
- Functions and code organization
- Working with files and directories
- Error handling and debugging
- Hands-on exercises

### Day 2: Working with Data and the Web

- Working with structured data
- JSON and CSV files
- HTTP and web APIs
- Introduction to web scraping
- Using Scrapy for structured data collection
- Practical exercises involving publicly available data

### Day 3: Automation and Practical Applications

- Designing reusable scripts
- Transforming and analyzing collected data
- Generating useful reports
- Testing and troubleshooting
- Practical capstone project
- Applying Python to everyday tasks

The final curriculum will be refined based on learner
experience, learning objectives, and available workshop time.

## Example Projects

Planned exercises and projects may include:

- Automating file organization and processing
- Extracting information from structured documents
- Collecting publicly available web data
- Transforming data into useful reports
- Building small command-line utilities
- Combining multiple Python libraries to solve a practical
  problem
